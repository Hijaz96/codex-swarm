# Project Intelligence
Run `.codex/swarm/tools/swarm_project.py` from the project root for bounded, offline discovery. Output: `.codex/swarm/data/project-profile.json`. Optional user overrides: `.codex/swarm/data/project-preferences.json`. Review actual components before UI generation; distinguish installed from used. Do not read `.env` or secret values. Refresh after changes to dependencies, components or layouts.
