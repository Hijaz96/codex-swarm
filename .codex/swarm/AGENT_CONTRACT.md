# Subagent task contract

Before each delegation, supply:

- **Role:** Task-specific specialist expertise
- **Objective:** A concrete, verifiable deliverable
- **Context:** Relevant repository paths and existing conventions
- **Scope:** Allowed files; prohibited areas
- **Dependencies:** Inputs needed from other workstreams
- **Interface:** APIs, schemas, and outputs agreed with the lead
- **Verification:** Tests, review checklist, or evidence required
- **Return:** Summary, changed paths, test results, assumptions, and unresolved issues

Use read-only assignments for exploration when possible. Never give a specialist unrestricted secrets access just to speed up work.
